# THE-CELESTIAL-CRYSTAL-EMPORIUM---billing-and-inventory-system

**PROJECT OVERVIEW :**
The Celestial Crystal Emporium Billing and Inventory System is a Python-based application that allows users to browse available inventory, select items and quantities while shopping, and add their chosen products to a cart. It also calculates the total bill and manages inventory stock using CSV file handling and Pandas.

_**Features**__
1.Stores stock information such as price , item , quantity and displays.
2.Validates item by user.
3.Checks availability and stock of an item.
4.Allows users to select item and specify quantity.
5.Updates inventory after purchase.
6.Stores inventory data is CSV file.
7.User friendly

_**Technologies Used**_
Python 3.12.3
Pandas — used for handling and managing inventory data
CSV — used for reading/writing inventory data in CSV format

How to Run the Project:
1.Make sure Python 3.12.3 is installed on your system.

2.Install the Pandas library using the following command:
pip install pandas

3.Make sure that inventory.py and inventory.csv are located in the same folder.

4.Open the terminal in the project folder and run:
The Celestial Crystal Emporium - Billing and Inventory System.py

5.Follow the on-screen instructions to browse the inventory, select items, and generate your final bill.

_**Conclusion**_
This project demonstrates the use of Python 3.12.3, Pandas, conditional statements, loops, and CSV file handling to create a simple inventory and billing system. It allows users to view available products, select items, manage their cart, and generate a final bill based on their purchases.
